# Netflix Content Analytics Project

## Project Overview

This project analyzes Netflix's content library to uncover trends in content type, ratings, countries, genres, and release years.

The project follows a complete end-to-end data analytics workflow using:

* Excel
* SQL
* Python
* Power BI

## Dataset

Source: Kaggle

Dataset: Netflix Movies and TV Shows

Total Records: 8,807

Total Columns: 12

## Project Workflow

### Excel

* Data Cleaning
* Missing Value Analysis
* Pivot Tables
* Data Preparation

### SQL

* Content Distribution Analysis
* Country Analysis
* Ratings Analysis
* Content Growth Trends

### Python

* Exploratory Data Analysis (EDA)
* Missing Value Analysis
* Data Visualization using Pandas and Matplotlib

### Power BI

* Interactive Dashboard Development
* KPI Cards
* Content Distribution Analysis
* Country Analysis
* Genre Analysis
* Trend Analysis

## Key Findings

* Movies account for the majority of Netflix content.
* TV-MA is the most common content rating.
* Netflix experienced significant content growth after 2015.
* The United States contributes the highest number of titles.
* International Movies and Documentaries are among the most popular genres.

## Tools Used

* Python (Pandas, Matplotlib)
